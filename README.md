# 🎬 Movie Recommendation System

## 📌 Description  
This project builds a **Movie Recommendation System** that suggests similar movies based on user input.  
It uses **content-based filtering** by analyzing movie metadata such as genres, keywords, and descriptions.  
The final model is deployed as a simple web app using Flask or Streamlit.  

🎥 Tutorial Reference:  
[Movie Recommendation System - YouTube](https://www.youtube.com/watch?v=1xtrIEwY_zY&list=PLKnIA16_RmvY5eP91BGPa0vXUYmIdtfPQ&index=1)

---

## ✨ Features  
- Clean and efficient data preprocessing  
- Text vectorization using **TF-IDF** or **CountVectorizer**  
- **Cosine similarity** computation for finding related movies  
- Search interface for inputting movie titles  
- Web interface to display recommendations with posters  
- Deployed on **Heroku** for public access  

---

## 🛠️ Tech Stack  
- **Python 3.x**  
- **pandas**, **numpy**, **scikit-learn**  
- **Flask** or **Streamlit** (for web app)  
- **Requests**, **Pickle**, **TMDB API** (for posters)  
- **Heroku** (for deployment)
